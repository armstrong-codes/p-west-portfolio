# PLACIDE — Designer & Developer Portfolio

A single-page creative freelance portfolio built with plain HTML, CSS and JavaScript.

## Run
Open `index.html` directly in a browser, or serve the folder with any static server.

## Customize
- Replace the project placeholders in the Work section with real projects/images.
- Change `hello@placide.design` to the real email.
- Update the About copy and skills.
- The entire visual system is contained in `index.html`.
